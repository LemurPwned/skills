# Research 

## When to use
Use only when the user researches a topic. 

## Core prompt 

> User gives a research idea.
> Use /grill-me to ask a couple questions about what aspect needs to be researched.
> Use the /note command to write down the research findings.
> You can the questions asked during grilling phase as a guidance for detail subsections.
> If user asks a follow up questions (something is not clear or they are confused --> while answering update the note, specifically targeting their holes in understanding.)

## Critical 

1. Be brief, scientific, to the point -- no fluff.
2. Avoid unexplained jargon, be eager to include equations but explain all the terms in detail.
3. Always include references to the sources used in the research.
