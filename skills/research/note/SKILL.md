## When to use
Use only when the user wants to create an Obsidian note.

## Steps to create a note 

1. Use the `llm-notes` vaults for the Obsidian note creation
2. For each note, create a sensible title and between 3 and 5 tags that touch on both general and specific concepts in the note 
3. The note needs to be to the point. 

## Note structure 

--- 
title: <note title>
date: <note date>
tags: [<tag1>, <tag2>, <tag3>]
---

# <note title>

## Core concept 
<Between 3 and 5 sentences, describe the core concept of the note>
<You can add bullet points here as well in addition to the core concept>

## Sources
<Critical! Here put the original publications or sources for the note! Include links if possible.>

## Key details
<Expand your core concept section using a detail, with each section of the detail having a separate subheading and a tag.>
## <Detail 1>
## <Detail 2>
