# LemurPwned Skills

Barebones skill collection for coding agents.

## Install

```sh
npx skills@latest add LemurPwned/skills
```

## List

```sh
npx skills@latest add LemurPwned/skills --list
```

## Skills

- `grill-me`
- `caveman`
- `thermo-nuclear-code-quality-review`
